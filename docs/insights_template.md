# Insights & Interpretation

## 1. Dataset Profile

| Metric | Result |
|---|---:|
| Unique job postings | 1,200 |
| Posting date range | 3 January 2025 – 22 October 2026 |
| Distinct skills | 51 |
| Locations | 8 |
| Dataset source | Synthetic (simulated) dataset |

## 2. Key Findings

The findings below are calculated from the project's current simulated CSV files.

1. **Most represented role:** DevOps Engineer — 135 postings.
2. **Most frequently mentioned skill:** SQL — mentioned in 737 distinct job postings.
3. **Top entry-level skill:** SQL — mentioned in 447 entry-level postings.
4. **Role with the highest entry-level share:** Machine Learning Engineer — 74 of 111 postings, or approximately 66.7%.
5. **Location with the most postings:** Kolkata — 167 postings.
6. **Median salary difference between Fresher and Mid-level:** ₹7.6 LPA (Mid-level median ₹13.0 LPA minus Fresher median ₹5.4 LPA).
7. **Most common work mode:** On-site — 539 postings.

## 3. What These Findings Mean

In this simulated sample, DevOps Engineer is the most frequently represented job title, while SQL is the most commonly listed skill overall and among entry-level postings. Machine Learning Engineer has the highest entry-level share in this dataset, although this does not mean it is the easiest role to enter in the real job market. Kolkata has the largest number of postings in the sample, and on-site work is more common than hybrid or remote work. The median salary for Mid-level postings is ₹7.6 LPA higher than the Fresher median in this simulated dataset.

## 4. Limitations

- The records are synthetic and do not represent actual employer demand or real job offers.
- Company names, job postings, dates, and salary values were generated for portfolio demonstration.
- Job titles, skills, and experience levels are simplified categories.
- A skill appearing in a posting does not prove that it is a hiring priority or that candidates must be expert in it.
- Simulated salary values should not be used for salary negotiation or compensation decisions.
- The dataset is not a statistically representative sample of Indian startups.
- Results describe only this dataset and should not be generalized to the wider job market.

## 5. Conclusion

This project demonstrates an end-to-end analytics workflow: organizing job-posting and skill data in a relational structure, validating data quality, analyzing hiring-related questions with PostgreSQL, and preparing insights for Power BI reporting. The current results are useful for demonstrating analytical methods, not for making claims about actual startup hiring trends.
